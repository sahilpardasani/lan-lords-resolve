# 30-Minute Team Check

Each person posts only:

```text
OWNER:
STATUS: GREEN / YELLOW / RED
LAST PASS:
CURRENT BLOCKER:
NEXT 30 MIN:
NEEDS FROM:
FILES / ARTIFACTS PRODUCED:
```

Rules:
- no design debate in the status round;
- a RED owner names one blocking dependency;
- blockers go to the person who owns the layer;
- do not let the whole team swarm one problem unless it blocks Gate E.
