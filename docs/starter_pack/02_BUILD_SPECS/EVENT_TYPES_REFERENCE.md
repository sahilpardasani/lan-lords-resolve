- `STATE_TRANSITION`
- `EVIDENCE_READ`
- `MODEL_CALL_ADMITTED`
- `MODEL_CALL_COMPLETED`
- `AGENT_FINDING`
- `CANDIDATE_PROPOSED`
- `FALSIFICATION_RESULT`
- `MISSING_EVIDENCE_REQUESTED`
- `EVIDENCE_ADDED`
- `REHEARSAL_STARTED`
- `REHEARSAL_RESULT`
- `CONTRACT_CREATED`
- `APPROVAL_REQUESTED`
- `APPROVAL_GRANTED`
- `APPROVAL_REJECTED`
- `COMMIT_ADMITTED`
- `COMMIT_ATTEMPTED`
- `COMMIT_RESULT`
- `VERIFY_RESULT`
- `CANCEL_REQUESTED`
- `CANCELLED`
- `RECONCILE_REQUIRED`
- `RUN_CLOSED`
- `RUNTIME_STATS`

The UI reads these events; it does not independently decide run truth.
