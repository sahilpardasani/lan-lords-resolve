# Case 04 — Semiconductor Yield RCA

Yield fell from **94.2% to 81.7%** after maintenance on chamber C17. Several facts move together: a mass-flow controller was replaced, a recipe checksum changed, gas flow shifted +6.8%, and thickness variation increased. A global recipe rollback is tempting but confounded.

Resolve should identify competing hypotheses, ask for post-maintenance calibration evidence, isolate C17, and run a local/control-lot validation before a wider intervention.
