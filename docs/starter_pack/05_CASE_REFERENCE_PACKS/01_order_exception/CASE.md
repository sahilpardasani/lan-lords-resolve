# Case 01 — $2.4M Cross-Functional Order Exception

A strategic customer has a **$2.4M order due in 72 hours**. Only 65% is qualified; 35% is under quality hold. Missing the deadline creates **$180K/day** contractual exposure. No single SOP owns the answer.

Tempting first answer: release the held inventory and ship the full order.

Correct troubleshooting shape: detect that quality prevents that shortcut, request exact missing facts about supplier approval/split delivery/displacement/cost, then find a bounded plan that satisfies commercial and quality constraints.
